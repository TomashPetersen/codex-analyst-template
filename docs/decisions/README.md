# Решения

Один файл содержит одно устойчивое решение. Имя: `YYYY-MM-DD-<slug>.md`.

Используй [`TEMPLATE.md`](TEMPLATE.md). Полный lifecycle артефакта, правила machine fields, knowledge outcome и безопасных ссылок определяет единый [`knowledge/INDEX.md`](../../knowledge/INDEX.md). Обновляй status прозрачно и не стирай исходный контекст. Новый ADR создавай только при реальной смене базового архитектурного решения; hardening существующего решения оформляй дополнением к нему.

`README.md` и `TEMPLATE.md` не являются decision artifacts и исключаются из machine scan.

## Когда нужен ADR

Решение нужно, если выбран стек, изменена граница системы, принят труднообратимый компромисс, определена платформа deploy или отвергнута реалистичная альтернатива.
