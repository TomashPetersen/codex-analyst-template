# Кодовая база

Эта зона описывает фактическую структуру выбранного стека. Она не создает заранее `src/`, `app/`, `tests/`, `infra` или другие каталоги.

- [`overview.md`](overview.md) - entrypoints, modules, команды, tests, conventions, generated artifacts и технический долг.
- Архитектурный смысл: [`docs/architecture/`](../architecture/INDEX.md).
- Текущее поведение: код и тесты.

После изменения структуры обновляй карту по фактам и указывай `verified_at`.
