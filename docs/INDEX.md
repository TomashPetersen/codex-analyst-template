# Документация проекта

- [`architecture/INDEX.md`](architecture/INDEX.md) - системный контекст, границы, компоненты, данные, интеграции, trust boundaries и deployment.
- [`analysis/INDEX.md`](analysis/INDEX.md) - формальные use cases, FR/NFR, DATA/INT/SYS, AC, спецификации, изменения и review.
- [`codebase/INDEX.md`](codebase/INDEX.md) - фактические entrypoints, modules, команды, tests, conventions и технический долг.
- [`decisions/README.md`](decisions/README.md) - архитектурные и продуктовые решения с последствиями и откатом.

Код и тесты остаются источником истины о поведении. `docs/architecture/` владеет устойчивой технической архитектурой, а `docs/analysis/` - формальными аналитическими артефактами; один факт не дублируется между владельцами.
