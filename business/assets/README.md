# Материалы бизнеса и бренда

## Что хранить

- разрешенные отзывы и доказательства;
- собственные визуальные и текстовые ассеты;
- реестр лицензий и provenance внешних материалов;
- copy-bank с указанием источника и статуса.

Бренд-гайд или asset registry создается только при появлении реального материала. Ссылайся на него из [`go-to-market.md`](../go-to-market.md), не дублируй содержание.

Не хранить здесь секреты, необработанные персональные данные, материалы без права использования и автоматически скачанный контент без проверки лицензии.
