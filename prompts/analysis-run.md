# Анализ одного вопроса

```text
Задача: <ЗАДАЧА>. Ссылка на задачу (task_ref): <TASK_REF>.
Тип задачи (intent): <INTENT_ID>.

Используй it-analysis. Прочитай AGENTS.md, PROJECT.md, INDEX.md,
analysis/CONTRACT.md и указатели нужных разделов. Уточни, какое решение поможет
принять анализ, какие вопросы входят в работу, ее границы, источники,
условия остановки и разрешенные действия. Для одного такого анализа
не создавай план реализации.

Создай рабочий набор анализа только через scripts/new-analysis-run.ps1:
ровно восемь файлов. Передай до трех независимых вопросов подходящим агентам
проекта с доступом только для чтения. Ведущий аналитик (Lead Analyst) остается
единственным, кто пишет файлы, и сводит результаты. Затем отдельно запусти
analysis_reviewer для проверки и analysis_red_team для поиска контрпримеров.
Если работа с несколькими агентами недоступна, выполни те же роли последовательно
и явно зафиксируй этот способ работы.

Результат остается рабочим материалом. Не меняй основные документы проекта,
индекс Git или внешние системы, не выполняй действий с предложениями для базы
знаний и не выполняй commit или push без отдельного разрешенного порядка действий.
```
