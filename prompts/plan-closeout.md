# Завершение плана и отбор знаний

```text
Заверши <PLAN_REF>. Полностью прочитай план, раздел Resume checkpoint с состоянием
для продолжения, knowledge/INDEX.md и фактические изменения Git относительно
снимка перед задачей. Сверь критерии приемки, фазы, тесты, решения об архитектуре
(ADR) и затронутые основные документы. При расхождении или незавершенной работе
не ставь complete: сохрани точное состояние для продолжения со статусом blocked
и причиной блокировки.

Выдели только сведения, полезные после завершения задачи. Допустимо максимум
два предложения для базы знаний: один результат проекта и один повторяемый метод
с подтверждениями из двух независимых завершенных задач либо прямой поправкой
владельца. Не копируй полный план, изменения, код, тесты, журналы, секреты
или персональные данные. Автоматическое создание предложения в состоянии ready
допустимо только в active + safe-local; применение всегда требует отдельного
разрешения. Заполни result_refs, closeout_status, knowledge_outcome и итоговый
Resume checkpoint. Проверь указатель планов и только затем переведи план
в complete через scripts/set-plan-status.ps1.
```
