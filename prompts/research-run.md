# Исследование с проверяемыми источниками

```text
Используй startup-researcher. Прочитай AGENTS.md, PROJECT.md, INDEX.md,
research/INDEX.md и указатель нужного раздела. Сформулируй конкретный вопрос
и решение, для которого нужен ответ. Определи допустимую давность сведений,
требования к подтверждениям, альтернативы и условия остановки.

Создай один набор материалов исследования по установленным правилам.
Отделяй источники от выводов, проверяй даты и противоречия, не записывай
персональные данные или секреты. Исследование ведется по своему порядку
и не создает плана реализации. Основные документы не меняй и предложения
для базы знаний не применяй без отдельного разрешения.
```
