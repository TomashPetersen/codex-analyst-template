# Заполнение паспорта проекта

```text
Прочитай AGENTS.md и PROJECT.md. Задай короткий блок вопросов для обязательных
полей: название, lowercase slug, одно предложение о проекте, роль или псевдоним
владельца, стадия, проблема, аудитория, границы, критерии успеха и ограничения.

Не требуй технический стек на стадии идеи. Не запрашивай ФИО и контакты. Покажи
готовый draft, затем после подтверждения обнови только PROJECT.md. Не активируй
проект и не создавай Git baseline без отдельной прямой команды.
```
