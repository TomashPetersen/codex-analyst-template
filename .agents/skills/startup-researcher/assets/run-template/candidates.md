# Кандидаты

## Правила

- Hard gates проверяются до сравнения направлений.
- Направление и уверенность записываются раздельно.
- Суммарный числовой рейтинг не используется.
- Число строк, доменов или агентов не заменяет независимость `origin_group_id`.
- Evidence refs записываются только как `evidence:<evidence_id>`; safety scanner применяется ко всему файлу.
